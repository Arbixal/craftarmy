## The question

Which owned materials should shopping lists subtract, how should uncertain skill-ups
affect quantities, and may default leveling routes consume concentration or Moxie?
Should steps merely guide manual crafting or include a crafting action?

## Thread

> Append-only; add dated sections rather than rewriting earlier discussion.

### 2026-11-05 — opened after grill Round 2

The user confirmed adaptive curated routes and three milestone targets. Material
lists must now be defined for remaining work, accurate inventory scope, quality
requirements, intermediates, and uncertain skill gains. The initial design recommends
conservative quantities and current-character stock before shared-bank reservations,
but these details are not accepted yet.

Resource policy matters because concentration has value beyond leveling and Moxie
can gate purchases. Do not assume accepted knowledge-first prioritization grants
unlimited spending. Owner: user for spending/workflow preferences, primary for
reliable inventory/crafting API constraints. Blocks shopping and guide execution
contracts, not the core dashboard.

### 2026-11-05 — grill Round 3 — accepted inventory, resource, and execution policies

User explicitly chose bags plus personal bank by default, with an option to include
Warband-bank materials. Warband inclusion is opt-in; other-alt holdings are not
automatically deducted. Maintain freshness and usability distinctions.

User accepted remaining-target material lists with a next-block option, separate
expected/contingency quantities, and updates after actual progress. Default routes
do not spend concentration; Moxie-priced unlock branches need explicit selection,
with blocked target consequences explained.

User replaced the proposed per-character/profession/target external lists with
exactly **one reusable CraftArmy list**. An explicit new list request replaces it
across character/profession changes. This is not authorization to replace unrelated
lists or to mutate Auctionator lists without a new export request. Other export
safeguards/fallbacks from the recommendation remain accepted.

User accepted opening recipes and observing manual crafts, not automatic crafting,
buying, or knowledge spending. → promoted to D09. This thread's product policies
are decided; external API details remain Q04 and reagent selection is Q09.
