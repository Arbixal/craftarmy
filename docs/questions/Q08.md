# Q08 — Knowledge-source guide coverage

> **Status:** open
> **Opened:** 2026-11-05 · **Last touched:** 2026-11-05

## The question

How far beyond crafting should the knowledge-first guide go: explain source unlocks,
include actionable one-time sources, or track weekly completion as well?

## Thread

> Append-only.

### 2026-11-05 — opened after grill Round 3

D06 prioritizes unlocking knowledge activities and affordable first crafts. This
exposes a scope boundary between a leveling/access guide and a recurring weekly
knowledge task manager. The original request does not explicitly require the latter.
Primary should recommend a bounded guide scope and let the user choose. Source IDs,
reward values, gates, and completion detection are research, not user homework.

Owner: user for scope; primary for source validation. Blocks final guide content
coverage, not dashboard collection.

### 2026-11-05 — grill Round 4 — accepted and promoted

User accepted actionable one-time knowledge sources and explanations of unlocking
recurring sources, with completion tracked only where reliably observable. Separate
knowledge earned now from future access unlocked. A full weekly checklist/reset
tracker is deferred under P03.

→ promoted to D11. Product coverage is decided; source IDs/rewards/gates and reliable
completion detection remain data-validation work, not another scope interview.
