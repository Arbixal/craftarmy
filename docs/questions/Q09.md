quality/useful products when skill and knowledge rewards would be unchanged?

### 2026-11-05 — opened after grill Round 3

default concentration spending. The material planner must keep reagent qualities
distinct, but the default selection policy has not yet been chosen. Avoid assuming
premium materials or high-quality outputs are needed merely to gain skill/knowledge.
Any quality-dependent task must retain its actual requirements.

Owner: user for intended output/cost tradeoff; primary for recipe requirements.
Blocks default reagent selection, not shopping aggregation mechanics.

### 2026-11-05 — grill Round 4 — accepted and promoted

without concentration. Higher-quality output premiums require selecting that
alternative. With unavailable prices, use the curated recommendation and explicitly
